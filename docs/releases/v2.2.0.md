# TVControl 2.2.0 — Reliability and Operations

TVControl 2.2.0 turns the original 88-tool TradingView controller into a 102-tool control, diagnosis, and recovery system. The release is focused on one outcome: an AI agent should know whether TradingView is healthy, understand which operations are safe, recover cleanly when Desktop disconnects, and leave evidence when a long-running workflow completes.

## Highlights

### Capability-aware control

`tv capabilities` maps every MCP tool to the TradingView APIs it needs. Runtime gates block an operation only when the live compatibility canary explicitly confirms a required API is absent. Recovery remains available when the canary itself cannot run.

Versioned compatibility snapshots distinguish a real critical break from ordinary method-surface drift, making TradingView Desktop updates easier to evaluate before using them in a live workflow.

### Reliability toolkit

- `tv chaos` plans fault scenarios without touching Desktop; `--allow-live-faults` explicitly enables bounded recovery tests.
- `tv soak` runs bounded health, stream, watchdog, restore, or sweep loops and writes an abort-safe receipt.
- `tv golden` verifies chart, Pine, strategy, watchlist, snapshot, and replay workflows with guaranteed cleanup paths.
- `tv watchdog` samples privacy-safe health transitions and can install a native user service with an explicit `--apply` flag.
- `tv support` creates a compressed diagnostics bundle stripped of symbols, account-linked values, URLs, titles, source code, secrets, home paths, and raw error text.

### Safer automation

Cross-process leases coordinate mutations from MCP clients and the `tv` CLI so two agents cannot silently change the same chart at once. Connection setup, renderer calls, public helper requests, tab creation, strategy reads, and chart restoration now have explicit bounds and clearer classified failures. Receipt and support-bundle output remains inside `~/.tv-mcp/`, and long-running streams stop promptly when interrupted.

### Better daily control

This release adds bulk watchlist operations, indicator-dialog search/add, saved-layout tab creation, bounded layout pagination, exact strategy targeting, stronger Windows/MSIX launch behavior, improved range loading, and more honest partial-result reporting.

## Compatibility

- No existing MCP tool was intentionally removed.
- Arbitrary `ui_evaluate` remains opt-in through `TV_MCP_ADVANCED=1`.
- Node.js 18.14.1 or newer is required.
- TradingView internal APIs remain undocumented and can change between Desktop releases; run `tv compatibility` and `tv capabilities` after updating Desktop.

## Validation

- 512 deterministic offline tests.
- ESLint across `src/` and `tests/`.
- Dependency vulnerability audit.
- npm package and clean-install smoke checks.
- Linux, macOS, and Windows CI on Node 18 and 22.
- Safe live TradingView health, capability, soak, and golden checks.
